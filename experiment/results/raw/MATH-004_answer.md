# MATH-004: 贝叶斯推理应用 — 答案（Group A 基线）

## 问题重述

- 检测准确率（Sensitivity）：P(阳性|有病) = 0.99
- 特异性（Specificity）：P(阴性|没病) = 0.99，即 P(阳性|没病) = 0.01
- 发病率（Prevalence）：P(有病) = 0.001 (0.1%)

## 1. 一次检测阳性后的患病概率

使用贝叶斯公式：

```
P(有病|阳性) = P(阳性|有病) × P(有病) / P(阳性)
```

其中 P(阳性) = P(阳性|有病)×P(有病) + P(阳性|没病)×P(没病)
           = 0.99 × 0.001 + 0.01 × 0.999
           = 0.00099 + 0.00999
           = 0.01098

```
P(有病|阳性) = 0.99 × 0.001 / 0.01098
             = 0.00099 / 0.01098
             ≈ 0.0902
             ≈ 9.02%
```

**自然语言解释**：即使检测呈阳性，实际患病的概率只有约9%。原因在于该病非常罕见（0.1%），所以假阳性（1%的999个健康人≈10个假阳性）远多于真阳性（99%的1个病人≈1个真阳性）。10个假阳性 vs 1个真阳性 → 阳性结果中只有约1/11是真正患病的。

## 2. 两次独立检测均阳性后的患病概率

将第一次检测的后验概率作为第二次检测的先验概率：

```
P(有病) = 0.0902（从第1步得到）
```

```
P(阳性) = 0.99 × 0.0902 + 0.01 × (1 - 0.0902)
        = 0.089298 + 0.009098
        = 0.098396

P(有病|两次阳性) = 0.99 × 0.0902 / 0.098396
                = 0.089298 / 0.098396
                ≈ 0.9075
                ≈ 90.75%
```

**自然语言解释**：两次独立检测均为阳性后，患病概率从9%飙升到约91%。第二次检测大幅排除了假阳性可能——第一次假阳性的概率是1%，连续两次都假阳性的概率是0.01×0.01=0.0001，极为罕见。

## 3. 发病率变为1%时的情况

```
P(有病) = 0.01
P(阳性) = 0.99 × 0.01 + 0.01 × 0.99
        = 0.0099 + 0.0099
        = 0.0198

P(有病|阳性) = 0.99 × 0.01 / 0.0198
             = 0.0099 / 0.0198
             = 0.5
             = 50%
```

**自然语言解释**：当发病率从0.1%变为1%（提高10倍），一次阳性后患病概率从9%变为50%。此时真阳性（99个）和假阳性（99个）数量相当，所以阳性结果只有一半的可能是真正患病。这说明**先验概率（发病率）对后验概率的影响极大**。

## 总结

| 场景 | 发病率 | 阳性次数 | P(患病\|阳性) |
|------|--------|----------|---------------|
| Q1   | 0.1%   | 1次      | 9.02%         |
| Q2   | 0.1%   | 2次      | 90.75%        |
| Q3   | 1%     | 1次      | 50.00%        |

核心启示：**在高特异性检测中，罕见病的阳性结果需要谨慎解读**。这就是为什么医学筛查通常需要确认性检测——单一检测的阳性预测值在低发病率人群中可能低得惊人。
