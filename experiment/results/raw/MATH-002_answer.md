## 算法A：嵌套循环，j步长×2

```python
for i in range(n):
    j = i
    while j < n:
        # O(1) 操作
        j *= 2
```

内循环：j从i开始，每次翻倍→步数=⌈log₂(n/i)⌉

总操作数：
```
T(n) = Σᵢ₌₀ⁿ⁻¹ ⌈log₂(n/max(i,1))⌉
     ≈ Σᵢ₌₁ⁿ⁻¹ log₂(n/i) + O(n)
     = log₂(nⁿ⁻¹/((n-1)!)) + O(n)
     = (n-1)log₂n - log₂((n-1)!) + O(n)
```

用Stirling近似：
```
log₂((n-1)!) ≈ (n-1)log₂(n-1) - (n-1)/ln2
T(n) ≈ n·log₂n - n·log₂n + n/ln2 + O(n)
     ≈ n/0.693 + O(n) ≈ 1.44n + O(n)
```

**大O**：Θ(n)。每个i对应约log₂(n/i)次操作，总和~n。

数值验证（n=100）：外层100次，内层平均约log₂(100/50)≈1次→~200次操作。实际~100×均值。

## 算法B：T(n) = 3T(n/2) + n²

主定理：a=3, b=2, f(n)=n²
```
n^(log₂3) ≈ n^1.585
f(n) = n²
```
f(n) = n² 以 n^0.415 因子大于 n^(log₂3)。Case 3：f(n) = Ω(n^(log₂3+ε))，ε≈0.415。

检查正则条件：3·(n/2)² = 3n²/4 ≤ c·n²，取c=3/4<1 ✅

**T(n) = Θ(n²)**（f(n)主导）

数值验证（n=100）：
- 递归深度：log₂100≈7层
- 顶层：100²=10000
- 第1层：3×(50²)=7500
- 第2层：9×(25²)=5625
- 总和：10000×∑(3/4)ᵏ ≈ 10000×4 = 40000

## 算法C：子串验证

对于每个长度为k的子串（n-k+1个），调用O(k)的验证函数。
```
T(n,k) = (n-k+1) × k
```

最坏情况（k≈n/2）：
```
T(n) = (n/2+1) × n/2 ≈ n²/4
```

**大O**：O(n·k)。如果k固定（如k=常数），O(n)；如果k∝n，O(n²)。

数值（n=100, k=10）：91×10=910次操作。

## 汇总

| 算法 | 递推/求和 | 大O | n=100估算 |

| B | 3T(n/2)+n² | Θ(n²) | ~40000 |
| C | (n-k+1)×k | O(nk) | ~910 (k=10) |
