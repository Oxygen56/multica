# RESEARCH-015: GitHub Actions vs GitLab CI vs Jenkins — 答案（Group A 基线）

## 场景：10人团队，GitHub托管代码

## 对比

| 维度 | GitHub Actions | GitLab CI | Jenkins | CircleCI | Buildkite |

## 推荐：GitHub Actions

**理由**：
1. 与GitHub原生集成——代码、PR、CI在同一平台，无上下文切换
2. 12000+ Actions生态——几乎不需要从零写任何集成
3. 2000免费分钟/月对10人团队足够（按每天20次构建×5min≈2000min/月刚好）
4. 自托管runner简单——超出免费额度后在服务器上跑 `./run.sh` 一行命令
5. YAML配置学习成本低，全团队都能维护

## 其次推荐：Buildkite（如果需要更复杂的Pipeline）

Buildkite在混合执行（部分云端部分自托管）和Pipeline可视化方面优于GitHub Actions，但10人团队不需要这个复杂度。

## Jenkins不推荐的原因

- 配置和维护成本高（需要专人管理Jenkins服务器+插件升级+安全补丁）
- 10人团队不值得投入一个全职CI管理员
- Pipeline as Code不如YAML简洁
