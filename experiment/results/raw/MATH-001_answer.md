# MATH-001: 概率问题：骰子游戏期望值 — 答案（Group A 基线）

## 1. 期望值计算

三个公平六面骰子，总可能结果：6³ = 216。

**三条（三个相同）**：6种组合（111,222,...,666），概率 = 6/216 = 1/36

**一对（恰好两个相同，第三个不同）**：
- 选哪两个骰子相同：C(3,2) = 3种
- 选对子的点数：6种
- 第三个不同的点数：5种
- 组合数：3 × 6 × 5 = 90
- 概率 = 90/216 = 15/36

**全不同**：216 - 6 - 90 = 120，概率 = 120/216 = 20/36

验证：6/216 + 90/216 + 120/216 = 216/216 ✅

**期望值**：
```
E = 100 × (6/216) + 10 × (90/216) + (-5) × (120/216)
  = 600/216 + 900/216 - 600/216
  = 900/216
  ≈ 4.167 元
```

## 2. 是否值得玩

期望值 ≈ +4.17元 > 0，**值得玩**。长期平均每局赚约4.17元。

## 3. 公平游戏的三条奖金

设新奖金为x元，期望值=0：
```
x × (6/216) + 10 × (90/216) + (-5) × (120/216) = 0
6x/216 + 900/216 - 600/216 = 0
6x + 300 = 0
x = -50
```

x为负意味着即使三条不给奖金（x=0），期望值已经是900/216-600/216=300/216≈1.39>0。**这个游戏对玩家总是有利的**——一对的10元奖金已经超过了全不同的损失。

验证：
- x=0：E = 0 + 900/216 - 600/216 = 300/216 ≈ 1.39元
- 要使期望值为0，三条需要**扣除50元**（负数奖金，即惩罚）

或者换个问法：如果保持三条100元不变，调整"全不同"的损失y：
```
100×(6/216) + 10×(90/216) + y×(120/216) = 0
600 + 900 + 120y = 0
y = -12.5 元
```
即全不同需要输12.5元才能使游戏公平。

## 自评

- ✅ 期望值计算正确：E = 900/216 ≈ 4.17元
- ✅ 值得玩（正期望）
- ✅ 公平奖金推导正确（三条需为-50或全不同需为-12.5）
