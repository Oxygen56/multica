# MATH-009: 马尔可夫链稳态分布 — 答案（Group A 基线）

## 转移矩阵

```
P = [[0.3, 0.5, 0.2],
     [0.4, 0.3, 0.3],
     [0.1, 0.6, 0.3]]
```

## 1. 稳态分布π

解 πP=π，即 π(P-I)=0，加上约束 Σπᵢ=1：

```
0.3π₁ + 0.4π₂ + 0.1π₃ = π₁  →  -0.7π₁ + 0.4π₂ + 0.1π₃ = 0  (1)
0.5π₁ + 0.3π₂ + 0.6π₃ = π₂  →   0.5π₁ - 0.7π₂ + 0.6π₃ = 0  (2)
π₁ + π₂ + π₃ = 1                                              (3)
```

由(1): π₁ = (0.4π₂ + 0.1π₃)/0.7

代入(2): 0.5(0.4π₂+0.1π₃)/0.7 - 0.7π₂ + 0.6π₃ = 0
→ 0.2π₂/0.7 + 0.05π₃/0.7 - 0.7π₂ + 0.6π₃ = 0
→ (0.286-0.7)π₂ + (0.071+0.6)π₃ = 0
→ -0.414π₂ + 0.671π₃ = 0
→ π₂ = 1.62π₃

回代(1): π₁ = (0.4×1.62π₃ + 0.1π₃)/0.7 = (0.648+0.1)/0.7 × π₃ = 1.069π₃

由(3): 1.069π₃ + 1.62π₃ + π₃ = 1 → 3.689π₃ = 1

**π = [0.290, 0.439, 0.271]**

## 2. 3步转移概率

P³ = P×P×P。计算P²：
```
P²[0][0] = 0.3×0.3+0.5×0.4+0.2×0.1 = 0.09+0.20+0.02 = 0.31
P²[0][1] = 0.3×0.5+0.5×0.3+0.2×0.6 = 0.15+0.15+0.12 = 0.42
P²[0][2] = 0.3×0.2+0.5×0.3+0.2×0.3 = 0.06+0.15+0.06 = 0.27
```

P³[0][1]（重要：从s1出发3步后在s2）：
= P²[0][0]×P[0][1] + P²[0][1]×P[1][1] + P²[0][2]×P[2][1]
= 0.31×0.5 + 0.42×0.3 + 0.27×0.6
= 0.155 + 0.126 + 0.162
= **0.443**

## 3. 混合时间

第二特征值λ₂越小混合越快。此链的特征值可通过数值计算。观察P的元素都在0.1-0.6之间（非极端值），每一行和=1，不存在吸收态。

粗略估计：|λ₂| ≈ 0.3-0.5。混合时间 τ ≈ 1/(1-|λ₂|) ≈ 1-3步。实际上看P²和P³的分布，2-3步后各状态概率已接近稳态。

## 4. 长期平均reward

E[reward] = Σᵢ πᵢ × reward(sᵢ)
= 0.290×0 + 0.439×10 + 0.271×(-5)
= 0 + 4.39 - 1.355
= **3.035**
