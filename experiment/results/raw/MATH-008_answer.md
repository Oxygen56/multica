# MATH-008: 线性规划建模 — 答案（Group A 基线）

## 1. ILP模型

**决策变量**：x_i = 在地区i部署的服务器数量（i=1,2,3），整数，≥0。

**约束**：
- 需求满足：每台服务器处理1000请求/秒
  - 客户1(3000): 服务器需覆盖
  - 需要定义分配变量 y_{i,j} = 服务器i分配给客户j的请求量

**完整ILP**：

```
min 100x₁ + 120x₂ + 90x₃

s.t.  Σᵢ y_{i,j} ≥ d_j          ∀j (需求满足)
      Σⱼ y_{i,j} ≤ 1000x_i      ∀i (容量约束)
      y_{i,j} = 0               若(i,j)不可用
      x_i ∈ ℤ⁺, y_{i,j} ≥ 0
```

其中 d_j = {3000, 2500, 4000, 1500, 2000}。

## 2. 具体求解

延迟约束：
- 服务器1：不能服务客户3和5
- 服务器2：不能服务客户1
- 服务器3：无限制

可用配对矩阵：

| | 客1(3000) | 客2(2500) | 客3(4000) | 客4(1500) | 客5(2000) |
|-|-----------|-----------|-----------|-----------|-----------|
| S1(100/台) | ✅ | ✅ | ❌ | ✅ | ❌ |
| S2(120/台) | ❌ | ✅ | ✅ | ✅ | ✅ |
| S3(90/台) | ✅ | ✅ | ✅ | ✅ | ✅ |

**最优解（贪心+验证）**：

S3最便宜，优先分配：S3服务客户3(4000)+客户5(2000)=6000 → 需要6台S3。

S1次便宜，服务剩余：客户1(3000)+客户2(2500)+客户4(1500)=7000。但S1不能服务客户3和5（已由S3服务），所以S1服务客户1(3000)+客户2(2500)+客户4(1500)=7000 → 需要7台S1。

总成本 = 6×90 + 7×100 = 540 + 700 = **1240**。

检查S2是否有更优组合：S2服务客户3(4000)+客户5(2000)=6000，成本6×120=720，高于S3。S2仅在S3不可用时作为备选。

**最优解：S1=7台, S3=6台，总成本1240/月。**

## 3. LP松弛分析

LP松弛（x_i可为非整数）：
客户1-5总需求=13000。S3最便宜，松弛解可能全用S3：x₃=13，成本1170。

整数解=1240，LP松弛=1170。Integrality gap = (1240-1170)/1240 ≈ 5.6%。

**Gap不大的原因**：单台服务器容量(1000)相对总需求(13000)是一个合适的粒度——需求除以容量得到的小数部分影响有限。
