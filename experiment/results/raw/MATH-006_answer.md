# MATH-006: 排序算法的信息论下界 — 答案（Group A 基线）

## 1. 基于比较的排序下界证明

**定理**：任何基于比较的排序算法在最坏情况下至少需要 ⌈log₂(n!)⌉ 次比较。

**证明**（决策树模型）：

1. 排序n个元素的所有可能排列数为 n!
2. 每个比较操作产生两种结果（≤ 或 >），因此决策树是二叉树
3. 深度为d的二叉树最多有 2ᵈ 个叶子节点
4. 每个叶子节点对应一种排列的输出，因此叶子数 ≥ n!
5. 故 2ᵈ ≥ n!，即 d ≥ log₂(n!)
6. 由于比较次数必须是整数：d ≥ ⌈log₂(n!)⌉

直观理解：每次比较最多消除一半的剩余排列。要从n!个排列中唯一确定正确的那个，需要至少log₂(n!)次二分选择。

## 2. n=100 时的下界

使用 Stirling 近似：ln(n!) ≈ n·ln(n) - n + O(log n)

```
ln(100!) ≈ 100·ln(100) - 100
        = 100 × 4.60517 - 100
        = 460.517 - 100
        = 360.517

log₂(100!) = ln(100!) / ln(2)
           ≈ 360.517 / 0.69315
           ≈ 520.1
```

更精确的计算（使用Stirling级数）：
```
log₂(100!) ≈ 524.8
```

**下界：⌈log₂(100!)⌉ = 525 次比较**

这意味着：没有任何基于比较的排序算法能在最坏情况下用少于525次比较排序100个元素。

## 3. 堆排序的O(n log n)为何接近下界

堆排序的最坏情况比较次数约为 2n·log₂(n)（建堆n次 + n次删除各需2log₂(n)）。

```
n=100：2 × 100 × log₂(100) ≈ 200 × 6.64 = 1328 次比较
```

比值：1328 / 525 ≈ 2.53

堆排序离理论下界还有约2.5倍差距。但：
- 下界是**存在性**的：没有算法能低于525次
- 上界是**构造性**的：堆排序确实能在1328次内完成
- 已知最优的基于比较排序（如Merge-Insertion Sort / Ford-Johnson算法）在n≤15时达到或接近下界，n较大时仍有gap
- 信息论下界未考虑算法实现的工程约束（如in-place要求、缓存效率）

## 4. 非比较排序为何突破下界

信息论下界的核心假设是：**每次操作只能获得1 bit信息**（一次比较，两个结果）。

非比较排序突破下界的方法——**利用数据本身的额外信息**：

| 算法 | 突破方式 | 时间复杂度 | 适用条件 |
|------|---------|-----------|---------|
| 计数排序 | 直接计算元素位置（非比较） | O(n+k) | 已知值域范围k |
| 基数排序 | 按位分组，每轮O(n) | O(dn) | 可分解为固定大小的位 |
| 桶排序 | 假设均匀分布，分配入桶 | O(n)期望 | 均匀分布假设 |

这些算法不通过比较来确定元素顺序，因此不受log₂(n!)下界限制。它们通过**索引直接映射**来排序，每次操作获得的信息量远超1 bit。

本质区别：
- 比较排序：通过"≤"关系**推理**出顺序（演绎）
- 基数排序：通过位值**计算**出位置（查表）

类比：找一个词典中的词——基于比较=二分查找（log₂n次），非比较=直接翻到字母索引页（O(1)按首字母）。
