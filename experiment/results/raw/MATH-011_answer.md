# MATH-011: 递归关系求解 — 答案（Group A 基线）

## 1. T(n) = T(n-1) + n, T(1) = 1

**展开法求解：**

```
T(n) = T(n-1) + n
     = T(n-2) + (n-1) + n
     = T(n-3) + (n-2) + (n-1) + n
     ...
     = T(1) + 2 + 3 + ... + n
     = 1 + Σᵢ₌₂ⁿ i
     = Σᵢ₌₁ⁿ i
     = n(n+1)/2
```

**验证**（代入原式）：
```
T(n) - T(n-1) = n(n+1)/2 - (n-1)n/2 = n/2[(n+1)-(n-1)] = n/2 × 2 = n ✅
T(1) = 1×2/2 = 1 ✅
```

**闭合形式**：**T(n) = n(n+1)/2 = O(n²)**

## 2. T(n) = 2T(n/2) + n log n, T(1) = 1

**主定理分析**（Master Theorem Case 2 扩展）：

标准形式：T(n) = aT(n/b) + f(n)，其中 a=2, b=2, f(n) = n log n

```
n^(log_b a) = n^(log₂ 2) = n¹
f(n) = n log n
```

比较 f(n) 与 n^(log_b a)：
- f(n) = n log n，n^(log_b a) = n
- log n > 常数，所以 f(n) 以 log n 因子大于 n^(log_b a)

适用主定理 Case 2 扩展（当 f(n) = Θ(n^(log_b a) · log^k n) 且 k ≥ 0）：
```
k = 1，故 T(n) = Θ(n · log² n)
```

**精确界**：**T(n) = Θ(n log² n)**

## 3. T(n) = T(n/3) + T(2n/3) + n, T(1) = 1

**递归树法：**

第0层：n
第1层：(n/3) + (2n/3) = n
第2层：(n/9 + 2n/9) + (2n/9 + 4n/9) = (3n/9) + (6n/9) = n
第k层：n

每层工作量都是n。树深度由最慢分支决定：n → (2/3)n → (2/3)²n → ... → 1
深度 h 满足 (2/3)^h · n ≈ 1，即 h = log_{3/2} n

```
T(n) ≈ n × log_{3/2} n = Θ(n log n)
```

**验证**（代入猜测 T(n) = cn log n）：
```
T(n) = c(n/3)log(n/3) + c(2n/3)log(2n/3) + n
     = cn/3[log n - log 3] + 2cn/3[log n + log 2 - log 3] + n
     = cn log n[(1/3 + 2/3)] + cn[(-1/3)log 3 + (2/3)(log 2 - log 3)] + n
     = cn log n + cn[log 2^(2/3) - log 3] + n
     = cn log n + cn[log(∛4 / 3)] + n
```

令括号内为负值 c[log(1.587/3)] ≈ c[-0.92]，取足够大的c，使 cn log n 项主导。✅

**闭合形式**：**T(n) = Θ(n log n)**
