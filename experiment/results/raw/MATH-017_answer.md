# MATH-017: HyperLogLog基数估计 — 答案（Group A 基线）

## 1. 最长连续零位的直觉

n个随机二进制字符串，每个bit独立随机。第i位是首个1的概率=1/2^i。前k位都是0的概率=1/2^k。

n个字符串中最长前缀零位≈log₂(n)。倒数：2^(最长零位)≈n。把二进制字符串看作均匀分布的哈希值，用"最长连续零位"来估计不同哈希值的数量。

## 2. 概率推导

单个随机字符串前k位都是0的概率 = 1/2^k。n个独立字符串至少有一个前k位全0的概率：
```
P(至少一个前k位全0) = 1 - P(全部都不是)
                    = 1 - (1 - 1/2^k)^n
```

取k≈log₂(n)：P ≈ 1 - (1-1/n)^n ≈ 1 - 1/e ≈ 0.632

取k≈log₂(n)+1：P ≈ 1 - (1-1/(2n))^n ≈ 1 - e^{-0.5} ≈ 0.393

**结论**：最可能观察到的最长零位约在log₂(n)附近，可以用来估计n。

## 3. 调和平均 vs 其他

HLL用调和平均（harmonic mean）而非算术平均：

```
算术平均：μ = (Σx_i)/m  → 受极端值影响大
调和平均：μ = m/(Σ 1/x_i) → 对异常值更鲁棒
```

在HLL中，一个桶出现异常大的值（对极大值）会毁掉算术平均。调和平均将异常值的贡献抑制为1/x，结果更稳定。这就是Flajolet选择调和平均的核心原因。

## 4. 误差计算

标准HLL：m=16384桶（2^14），基数n=1亿。

相对标准误差 ≈ 1.04/√m = 1.04/128 ≈ **0.81%**。

1亿的估计值会在 99.2M~100.8M 之间（68%置信区间）。
